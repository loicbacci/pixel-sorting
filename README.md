# Pixel Sorting

A web-based pixel sorting application built with Preact, Vite, and Tailwind CSS. Upload images and compute lightness threshold regions.

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- pnpm package manager

### Installation

```bash
pnpm install
```

### Development

```bash
pnpm dev
```

Starts a dev server

### Production Build

```bash
pnpm build
```

Builds for production, emitting to `dist/`

```bash
pnpm preview
```

Starts a server to test production build locally
